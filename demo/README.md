# 웹 데모 사용 안내

**[모아오더 열기](https://udder-purify-retract.ngrok-free.dev/)** · [시연 영상](https://youtu.be/Sa-5V4HNdrk) · [프로젝트 소개](../README.md)

## 사용 순서

1. 휴대폰의 Safari·Chrome 또는 PC 브라우저로 접속합니다.
2. 방문할 매장을 선택하고 해당 매장의 메뉴를 확인합니다.
3. 마이크 권한을 허용하고 주문 대화를 녹음합니다.
4. 녹음을 종료하면 서버가 음성을 분석합니다.
5. 화자별 최종 주문, 대화 원문과 변경 이력을 확인합니다.

운영 웹에서는 음성 파일 업로드와 추가 주문도 체험할 수 있습니다. 운영 웹은 개선 버전이며 이 저장소의 기준 코드와 기능이 일부 다릅니다.

## 결과 확인

| 화면 | 확인할 내용 |
|---|---|
| 최종 주문 | 사람별 메뉴와 수량 |
| 화자별 대화 | 누가 언제 어떤 말을 했는지 |
| 주문 변경 이력 | 메뉴 추가·교체·취소 과정 |
| 원음·결과 다운로드 | 인식 결과 검토와 기록 저장 |

화자 번호와 아이콘은 발화를 구분하기 위한 표시입니다. 실제 이름이나 좌석을 자동으로 알아내는 기능은 아닙니다. 확인 필요 표시가 있으면 원음과 주문 내용을 함께 확인해 주세요.

## 접속과 녹음

- 서버와 HTTPS 터널이 실행 중일 때 접속할 수 있습니다.
- 접속 키를 요청하면 운영자가 공유한 전체 접속 링크를 사용합니다. 키는 저장소에 공개하지 않습니다.
- 마이크는 페이지를 연 기기의 것을 사용합니다. 녹음이 안 되면 브라우저의 마이크 권한과 입력 장치를 확인합니다.
- 휴대폰 녹음은 HTTPS에서 사용하고, 녹음 중에는 화면을 켜둡니다.
- 목적지와 메뉴는 등록된 목록을 사용합니다. 메뉴의 실시간 판매 여부를 조회하는 서비스는 아닙니다.

## 직접 서버 실행하기

환경과 모델을 먼저 준비한 뒤 저장소 루트에서 실행합니다.

```bash
bash demo.sh
```

기본 주소는 `http://127.0.0.1:8765`입니다. 터미널에 출력되는 접속 키 포함 링크를 이용합니다. 다른 기기에서는 해당 서버에 연결된 HTTPS 주소가 필요합니다.

설치와 경로 설정은 [개발 환경 안내](../docs/SETUP.md)를 참고하세요. 녹음과 분석 결과는 기본적으로 `demo/sessions/`에 저장됩니다.
