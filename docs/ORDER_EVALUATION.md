2026-11-15, 로컬 RTX 5090 환경의 단일 측정입니다. 시간은 모델 로딩·화자분리·음원분리·ASR을 제외합니다. 정답은 녹음에 사용한 대본의 최종 메뉴와 수량이며 옵션은 채점하지 않았습니다. F1은 (화자, 메뉴, 수량) 조합 기준입니다. 정답 대본과 실제 ASR은 발화 분할도 달라 차이를 모두 글자 인식 오류로 설명할 수 없습니다.

일반 별칭은 기본 Qwen도 해석했습니다. 후보 추가만으로 심한 오인식은 복구되지 않았으며, 모호한 취소와 없는 메뉴의 임의 대체도 두 방식 모두에서 발견됐습니다. 음원 처리에서 발화가 합쳐지는 문제 역시 후속 개선 대상입니다. 10개 사례로 일반 성능을 단정하지 않습니다.

사용자의 원본 녹음, 세션 결과, 인증 정보와 모델 가중치는 공개하지 않습니다. 자동 테스트는 후보 생성 및 상태 검증을 확인하며 모델 정확도를 보장하지 않습니다. 기존 VALIDATION.md는 이전 기준 구현의 기록입니다.
